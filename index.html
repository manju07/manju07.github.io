02Intuit

A quote MCP server, then the plugin people install

Engineered an MCP server from scratch with FastMCP: 21 tools, covering quote GraphQL plus 18 MXS recommendation tools, with marketplace governance. Claude Code and Cursor agents can query quotes, run the models, compare pricing strategies, and validate inputs against production CPQ. Commerce agents moved to enterprise-wide production GA.

Wrapped that server as the CPQ Quote Plugin, an Intuit Desktop developer extension. Quote lookup by id, contract, or opportunity; ML recommendations; multi-strategy price comparison; catalog browsing; price estimation; and pre-submission validation. It holds official org-wide status on the AI Plugins marketplace, so a team installs it once.

Seller systems for the marketplace
